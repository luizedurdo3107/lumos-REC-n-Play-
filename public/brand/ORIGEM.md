# Ativos de marca

Arquivos separados encontrados entre os materiais compartilhados na conversa. Os PNGs foram copiados integralmente, sem trocar o desenho ou recriar o lettering.

| Arquivo do projeto   | Material de origem                               |
| -------------------- | ------------------------------------------------ |
| `lumos-logo.png`     | Logo circular Lumos Connect com mascote robô.png |
| `lumos-mascot.png`   | Mascote robô Lumos acenando.png                  |
| `norya-logo.png`     | Logo norya com beija-flor e assinatura.png       |
| `norya-wordmark.png` | Logo minimalista norya com subtítulo.png         |
| `norya-mascot.png`   | Mascote pássaro azul acolhedor.png               |

O mascote não é ampliado a partir de uma miniatura de tela de onboarding. Nenhuma logo é extraída da estampa da roupa do robô. O CSS adapta o tamanho de exibição e integra o fundo claro das ilustrações à página. No tema escuro, os arquivos com fundo claro permanecem em uma superfície clara para preservar as cores da marca.

Os ícones de funções (acessibilidade, áudio, calendário, biblioteca etc.) são SVGs do pacote `lucide-react`; não substituem os símbolos das marcas.
